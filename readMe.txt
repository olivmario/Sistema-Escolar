PROJETO – Foco em Programação Orientada a Objetos 

Este repositório contém um projeto desenvolvido para a cadeira de POO.  
O objetivo do trabalho é implementar um Sistema Escolar com duas formas de interação:

1. Versão via Terminal  
   - Permite cadastrar alunos, professores, disciplinas e outras operações básicas.  
   - Totalmente executado na linha de comando.  

2. Versão Web  
   - Desenvolvida utilizando o framework Spring Boot.  
   - Disponibiliza os mesmos recursos da versão de terminal, porém através de páginas web e rotas HTTP.  

Ambas as versões utilizam os conceitos fundamentais de Programação Orientada a Objetos, tais como:  
- Classes e Objetos  
- Encapsulamento  
- Herança  
- Polimorfismo  
- Coleções  
- Camadas de serviço e modelo

Este projeto foi criado com fins educativos, para demonstrar como aplicar princípios de POO tanto em aplicações locais quanto em aplicações web.
